# Лабораторна робота 5: Принцип поліморфізму


## Завдання 1. Клас `TimeSpan` та перевантаження методів

Реалізуйте клас `TimeSpan`, який зберігає часовий інтервал у годинах та хвилинах.

Наприклад:

```text
2 години 30 хвилин
```

Клас повинен підтримувати створення часових інтервалів різними способами, додавання та віднімання часу, масштабування інтервалу та обчислення його повної тривалості.

---

### Обмеження класу

Часовий інтервал повинен завжди залишатися коректним:

- інтервал не може бути від'ємним;
- кількість годин може бути `0` або більше;
- кількість хвилин у внутрішньому представленні повинна бути від `0` до `59`;
- якщо під час операції кількість хвилин стає більшою за `59`, потрібно виконати перерахунок у години.

Наприклад:

```text
2 години 75 хвилин → 3 години 15 хвилин
```

Поля класу повинні бути `private`.

---

### 1. Конструктори

Використовуючи **перевантаження конструкторів**, реалізуйте чотири способи створення `TimeSpan`.

#### Конструктор без аргументів

```java
TimeSpan()
```

Створює інтервал:

```text
0 годин 0 хвилин
```

#### Конструктор з одним аргументом

```java
TimeSpan(int minutes)
```

Аргумент задає загальну кількість хвилин.

Наприклад:

```java
new TimeSpan(150)
```

повинен створити інтервал:

```text
2 години 30 хвилин
```

Значення `minutes` не може бути від'ємним.

#### Конструктор з двома аргументами

```java
TimeSpan(int hours, int minutes)
```

Аргументи задають години та хвилини.

Вимоги:

```text
hours >= 0
0 <= minutes <= 59
```

Наприклад:

```java
new TimeSpan(2, 30)
```

створює інтервал:

```text
2 години 30 хвилин
```

#### Конструктор копіювання

```java
TimeSpan(TimeSpan span)
```

Створює новий часовий інтервал із такими самими значеннями годин і хвилин, як у переданого об'єкта.

Для отримання значень використовуйте:

```java
span.getHours()
span.getMinutes()
```

---

### 2. Методи отримання значень

#### `getHours()`

```java
public int getHours()
```

Повертає кількість повних годин без урахування хвилин.

Наприклад, для інтервалу:

```text
2 години 15 хвилин
```

метод повертає:

```text
2
```

#### `getMinutes()`

```java
public int getMinutes()
```

Повертає хвилинну частину інтервалу без урахування годин.

Для інтервалу:

```text
2 години 15 хвилин
```

метод повертає:

```text
15
```

---

### 3. Перевантажені методи `add()`

Реалізуйте три перевантажені методи додавання часу.

#### Додавання годин і хвилин

```java
public void add(int hours, int minutes)
```

Додає вказану кількість годин і хвилин до поточного інтервалу.

Вхідні аргументи повинні задовольняти умовам:

```text
hours >= 0
0 <= minutes <= 59
```

Після додавання потрібно нормалізувати хвилини.

Наприклад:

```text
2 год 15 хв + 1 год 45 хв = 4 год 0 хв
```

#### Додавання хвилин

```java
public void add(int minutes)
```

Додає до поточного інтервалу задану загальну кількість хвилин.

Наприклад:

```text
1 год 40 хв + 50 хв = 2 год 30 хв
```

Аргумент не може бути від'ємним.

#### Додавання іншого `TimeSpan`

```java
public void add(TimeSpan span)
```

Додає до поточного інтервалу інший часовий інтервал.

Для отримання значень використовуйте:

```java
span.getHours()
span.getMinutes()
```

Наприклад:

```text
1 год 20 хв + 2 год 50 хв = 4 год 10 хв
```

---

### 4. Перевантажені методи `subtract()`

Реалізуйте три перевантажені методи віднімання часу.

#### Віднімання годин і хвилин

```java
public void subtract(int hours, int minutes)
```

Віднімає вказаний часовий інтервал від поточного.

Вхідні аргументи повинні задовольняти умовам:

```text
hours >= 0
0 <= minutes <= 59
```

Якщо інтервал, який потрібно відняти, більший за поточний, поточний об'єкт не змінюється.

За бажанням замість цього можна викинути:

```java
IllegalArgumentException
```

якщо ви вже знаєте, як працюють виключення.

#### Віднімання хвилин

```java
public void subtract(int minutes)
```

Віднімає задану загальну кількість хвилин.

Наприклад:

```text
3 год 10 хв - 50 хв = 2 год 20 хв
```

Якщо віднімається більше часу, ніж містить поточний інтервал, залиште його без змін.

#### Віднімання іншого `TimeSpan`

```java
public void subtract(TimeSpan span)
```

Віднімає переданий часовий інтервал від поточного.

Для отримання значень використовуйте:

```java
span.getHours()
span.getMinutes()
```

Якщо `span` більший за поточний інтервал, поточний об'єкт не змінюється.

---

### 5. Повна тривалість інтервалу

#### `getTotalHours()`

```java
public double getTotalHours()
```

Повертає тривалість інтервалу в годинах як дробове число.

Наприклад:

```text
9 годин 45 хвилин
```

повинно дати:

```text
9.75
```

#### `getTotalMinutes()`

```java
public int getTotalMinutes()
```

Повертає повну тривалість інтервалу у хвилинах.

Наприклад:

```text
2 години 30 хвилин
```

повинно дати:

```text
150
```

---

### 6. Масштабування інтервалу

Реалізуйте метод:

```java
public void scale(int factor)
```

Метод збільшує поточний часовий інтервал у `factor` разів.

`factor` повинен бути більшим за `0`.

Наприклад:

```text
1 год 45 хв × 2 = 3 год 30 хв
```

Після множення потрібно правильно перерахувати хвилини в години.

---

### 7. Вимоги до реалізації

Клас повинен містити:

```java
public class TimeSpan
```

Поля повинні бути закритими:

```java
private
```

У класі повинні бути реалізовані такі конструктори:

```java
public TimeSpan()
public TimeSpan(int minutes)
public TimeSpan(int hours, int minutes)
public TimeSpan(TimeSpan span)
```

та методи:

```java
public int getHours()
public int getMinutes()

public void add(int hours, int minutes)
public void add(int minutes)
public void add(TimeSpan span)

public void subtract(int hours, int minutes)
public void subtract(int minutes)
public void subtract(TimeSpan span)

public double getTotalHours()
public int getTotalMinutes()

public void scale(int factor)
```

---

### 8. Приклади використання

```java
TimeSpan first = new TimeSpan();
TimeSpan second = new TimeSpan(150);
TimeSpan third = new TimeSpan(2, 30);
TimeSpan copy = new TimeSpan(third);

third.add(1, 45);

third.add(second);

third.subtract(1, 15);
third.subtract(30);
third.subtract(second);

int minutes = third.getTotalMinutes();

```

### 9. Зверніть увагу

Не створюйте окремі методи:

```java
addTimeSpan(...)
addMinutes(...)
subtractTimeSpan(...)
subtractMinutes(...)
```

якщо операція має один і той самий зміст.

Використовуйте **перевантаження**:

```java
add(...)
subtract(...)
TimeSpan(...)
```

Java визначить потрібний варіант методу або конструктора за кількістю та типами переданих аргументів.

## Завдання 2. Ланцюжок успадкування

У цьому завданні необхідно виконати такі дії:

1. Створіть клас `Person`, який повинен містити конструктор, гетери/сетери та наступні поля: прізвище, ім'я, вік. Перевизначте метод `toString()`, який повинен повертати рядок наступного формату:

```Людина <прізвище> <ім'я>, вік: <вік>```

2. Створіть клас `Student`, який має успадковуватись від класу `Person`. Додайте конструктор, гетери/сетери та наступні поля: група, номер студентського квитка. Перевизначте метод `toString()`, який повинен повертати рядок наступного формату:

```Студент групи <група>, <прізвище> <ім'я>, вік: <вік>. Номер студентського квитка: <номер>```

3. Створіть клас `Lecturer`, який має успадковуватись від класу `Person`. Додайте конструктор, гетери/сетери та наступні поля: кафедра; заробітна плата. Перевизначте метод `toString()`, який повинен повертати рядок наступного формату:

```Викладач кафедри <кафедра>, <прізвище> <ім'я>, вік: <вік>. Зарплата: <зарплата>```

4. Використовуючи висхідне перетворення, створіть у класі `Main` кілька об'єктів класів `Student` і `Lecturer`, після чого створіть масив, який міг би включати об'єкти класів `Person`, `Student`, `Lecturer`. Заповніть масив об'єктами цих класів.

5. Використовуючи цикл, зверніться до елементів масиву та виведіть у консоль, за допомогою методу `toString()`, інформацію від кожного об'єкта.

## Завдання 3. Гра RoShamBo

В даному репозиторії присутній модуль `roshambo`, який містить код для гри "Камінь-ножиці-папір". Виконайте наступні дії:

1. За допомогою механізму поліморфізму створіть класи ігрових фігур (Камінь, Ножиці, Папір), які успадковуються від `GameShape`;
2. Напишіть логіку методу `generateShape()`, який повертає одну із трьох випадкових фігур (об'єкт одного із трьох класів);
3. У методі `actionPerformed()` допишіть створення об'єкта ігрової фігури залежно від того, яку кнопку натиснув користувач (читайте коментарі всередині методу);
4. Реалізуйте метод `checkWinner()`, який приймає на вхід два об'єкти ігрових фігур - фігура комп'ютера та гравця. За допомогою оператора `instanceof` з'ясуйте, фактичний об'єкт якого класу ховається за змінною посиланням типу `GameShape`. Залежно від поєднання фігур метод повертає: `1` якщо виграв гравець, `-1` якщо виграв комп'ютер або `0` якщо нічия;
5. Зіграйте в гру і переконайтеся, що ваш код коректний та гра працює правильно.

## Завдання 4. Додаток Draw

В даному репозиторії присутній модуль `draw`, який містить код для додатку для малювання геометричних фігур.

Даний додаток дозволяє малювати прості фігури. За допомогою кнопок на верхній панелі потрібно обрати фігуру, після чого в полі малювання затиснути кнопку миші та визначити фігуру потрібних розмірів.

Завдання полягає в наступному:

1. Відкрийте проект, прочитайте коментарі, розберіться як працює додаток;
2. Використовуючи механізм поліморфізму, модифікуйте програму, додавши можливість вибирати та малювати еліпси (`Ellipse`);

Завдання на додатковий бал. Додайте в програму кнопку `Clear`, після натискання на яку програма повинна видалити з поля для малювання всі фігури.
